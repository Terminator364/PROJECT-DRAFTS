# Livraison / publication

- Chaîne DEV → PREVIEW → CANDIDATE → STABLE.
- A0 n'autorise aucune modification des liens publics, aucun nouveau jeu et aucune suppression d'archives.
- Toute STABLE exige un accord explicite utilisateur et G1–G5 documentés.
- Un HTTP 200, une archive ZIP ou 20 tests réussis n'est **pas** une acceptation du jeu.
- Garder la possibilité de rollback et de restaurer les sauvegardes ; ne jamais écraser sans test.
