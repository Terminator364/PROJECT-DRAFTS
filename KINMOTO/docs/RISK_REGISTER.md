# Risques prioritaires et garde-fous

| ID | Risque | Prévention | Condition d'arrêt |
|---|---|---|---|
| R01 | Licence asset inconnue | Registre par asset + preuve | Asset indispensable sans droit |
| R02 | Moto flotte/glisse | Piste étalon, caméra, roue-sol | Ressenti joueur insuffisant |
| R03 | Régression visuelle | Captures mêmes scènes | Perte non justifiée |
| R04 | RAM Android excessive | LOD, budget, benchmark physique | Crash/rechargement récurrents |
| R05 | Mobile seulement émulé | Appareil réel | Compatibilité non démontrée |
| R06 | Quota Work perdu | Ticket borné + commit + NEXT_ACTION | Aucun état sauvegardé |
| R07 | État divergence Drive/Git | SHA commit + version PDF | Deux autorités concurrentes |
| R08 | CI facturée | 0 runner, scripts locaux | Dépense potentielle |
| R09 | Sauvegarde détruite | Export/import, migrations/rollback | Migration non testée |
| R10 | Publication prématurée | STABLE uniquement avec GO utilisateur | Aucune approbation |
