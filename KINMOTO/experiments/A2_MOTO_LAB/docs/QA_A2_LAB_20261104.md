# KIN MOTO A2 — Rapport d'essais, édition du 4 novembre 2026

## Preuves positives

1. `npm run check` : vérifications de syntaxe JavaScript réussies.
2. `npm test` : **38 tests unitaires et d'intégration exécutés, 38 réussis, 0 échec** sur le labo A2. Comprennent 18 nouveaux tests moto : direction positive/négative, accélération, freinage, rotation des roues, glissement, grip, stabilité 10 000 frames, choc et réaction de voiture, triangles 3D et sauvegarde ; anciens tests de jeu et PWA conservés.
3. `python3 build.py` : HTML PWA autonome généré, 74–75 Ko d'HTML, sans moteur externe ni téléchargement de modèles.
4. **Essai visuel sur le véritable HP sous Opera** via le connecteur navigateur : page A2 accessible, menu puis 3D démarrée ; screenshot du rendu 3D avec pilote et moto ; HUD a affiché **53 à 59 FPS ponctuellement** en qualité économique avec GPU Intel UHD 620. Une capture avant correction montrant une voiture masquant la moto a conduit à un correctif de caméra et au masquage des touches sur PC ; seconde capture confirmait la visibilité de la moto.
5. **Scénarios dynamiques dans le véritable navigateur Opera sur HP** : `?qa=1&autoplay=1&autodrive=right` a indiqué `x=14.48`, `yaw=+0.850` ; `autodrive=left` sur origine de test neuve a indiqué `x=-14.50`, `yaw=-0.890`. Cela établit que les directions de simulation sont distinctes et correctement signées sur le navigateur observé. **Ce n'est pas une preuve de touches tactiles physiques.**
6. Déploiement de laboratoire sur Vercel, projet `kin-moto-a2-moto-lab`, indépendant des jeux existants ; déclaré `READY`, SSO désactivée.
