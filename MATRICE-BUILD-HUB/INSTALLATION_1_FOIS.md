# Installation une seule fois sur le PC

1. Télécharger le dépôt privé PROJECT-DRAFTS depuis GitHub et extraire le ZIP.
2. Ouvrir le dossier MATRICE-BUILD-HUB.
3. Clic droit sur bootstrap-pc.ps1 > Exécuter avec PowerShell.
4. Le script installe GitHub CLI avec winget si nécessaire et ouvre GitHub dans le navigateur pour l’authentification.
5. Après le message BUILD HUB PRET, l’installation est terminée.
6. Pour les productions suivantes, double-cliquer simplement hub.cmd et choisir 1, 2 ou 3.

Le PC ne compile pas l’APK : il pilote une machine Codespaces distante. GitHub Actions n’est pas utilisé.
