# TimePlus UI audit — v1.2.1

Corrections driven by real user-device screenshots:
- explicit status/navigation-bar safe areas;
- compact header and settings icon button;
- shorter manual-mode label;
- vertical summary card instead of squeezed columns;
- vertically stacked bottom actions;
- Settings metadata in vertical label/value blocks.

Release gate:
- >100,000 deterministic calculation cases;
- 360x800dp-equivalent and 412x915dp-equivalent viewports;
- font scales 1.0 and 1.25;
- Now, manual-start and Settings screenshots for each configuration;
- 12 emulator screenshots retained as evidence.
