# Architecture

Dix familles observées : ARCHITECTURE, ARCHIVES, BACKUPS, GOUVERNANCE, MEMOIRE, MODULES, OUTILS, PROJETS, SYSTEME, WATCHER. Les documents de direction et mémoire maître restent à la racine du projet.

Séparer moteur de collecte, modèle d'estimation, interface, historiques et tests. Le modèle d'autonomie doit être indépendant du collecteur Windows pour permettre des tests synthétiques. Le moteur publie une seule estimation valide à l'interface. Les réserves matérielle et Windows sont combinées par maximum, en unités d'énergie.
